CAP AGRÉG’ V3.1 — VERSION COMPLÈTE

Cette archive contient TOUS les fichiers à déposer à la racine du dépôt GitHub cap-agreg.

1. Décompresser le ZIP.
2. Sur GitHub, remplacer tous les fichiers existants par ceux de l'archive (ne pas supprimer d'autres fichiers ni les données Supabase).
3. Valider les changements (Commit changes), attendre la coche verte Actions.
4. Ouvrir Cap Agrég’, créer/ouvrir une fiche et choisir Cahier numérique.
5. Le titre 'Cahier Studio — Couleurs V3.1' confirme que la nouvelle version est chargée.
6. Sélectionner du texte, puis cliquer sur une grande pastille de couleur.

La configuration Supabase se conserve dans le navigateur ; si nécessaire se reconnecter dans Sync.
ATTENTION : ne pas inclure de clés secrètes Supabase dans les fichiers publics.
Fonctions non incluses : IA, gestion avancée des PDF, schémas automatiques complexes.
